# v11 — Live Command Center

v11 adds a presentation-focused real-time monitoring view.

It reuses the existing authenticated history API and does not alter the trained
models or prediction decision logic.

Features:
- current BPM card
- AI state and confidence
- demonstration risk score
- session reading count
- live trend chart
- rule/AI decision panel
- recent event stream
- automatic refresh every 2.5 seconds
- explicit responsible-use note

This is a software visualization layer. It does not claim that simulated data
is a clinical measurement.
